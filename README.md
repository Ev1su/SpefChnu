# Бот Правозахисного відділу СПЕФ

Асинхронний Telegram-бот на aiogram 3 для анонімних звернень студентів, анкет вступу, двосторонньої переписки та роботи адміністраторів у приватних чатах. Форум-групи не використовуються.

## Конфігурація

1. Створіть бота через @BotFather и отримайте `BOT_TOKEN`.
2. Дізнайтеся Telegram ID командою `/myid` у боті або через @userinfobot.
3. Скопіюйте `.env.example` у `.env` і заповніть `BOT_TOKEN`, `ADMIN_IDS`, `HASH_SALT`, `FERNET_KEY`.
   - `ADMIN_USERNAMES` необов'язкова: контакти для екрану «📞 Контакти» через крапку з комою, наприклад `@zxc — Admin;@misssparkk — Голова відділу`.
4. Кожен адміністратор один раз натискає `/start` у бота.
5. У зверненні студент може окремо увімкнути галочку «Передати @username». Без галочки username і user ID не передаються адмінам; з галочкою на картці є контактне посилання.
5. Генерація ключів:

```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
python -c "import secrets; print(secrets.token_hex(32))"
```

Попередження: втрачений або змінений `FERNET_KEY` робить старі зашифровані дані недоступними. `HASH_SALT` теж не слід змінювати.

## Локальний запуск

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
pip install -r requirements.txt -r requirements-dev.txt
python -m bot.main
```

## Docker

```bash
docker compose up -d --build
docker compose logs -f bot
```

## Oracle Cloud Always Free

1. Створіть VM Ubuntu у Oracle Cloud Always Free.
2. Встановіть Docker і Docker Compose за офіційною інструкцією Ubuntu.
3. Склонуйте проєкт: `git clone <repository-url>`.
4. Створіть `.env` із секретами.
5. Запустіть: `docker compose up -d --build`.
6. Перевірте: `docker compose ps` та `docker compose logs -f bot`.
7. Відкрийте доступ до SSH, але не відкривайте DB або токени в мережу. `restart: unless-stopped` забезпечує автозапуск контейнера.

Також підходять Google Cloud e2-micro (залежить від лімітів і регіону: безкоштовний ресурс обмежений) та Render/Koyeb (зручні платформи, але безкоштовні інстанси можуть спати або мати обмеження). Умови тарифів змінюються. Для конфіденційних даних краще сервер під контролем вашої організації.

Зберігайте копію `.env`, особливо `FERNET_KEY`, окремо в менеджері секретів або захищеному сховищі.

## Допущення

- За умови відсутності реальних реквізитів організації використовуються нейтральні формулювання в розділі «Про нас».
- Повна анонімність не гарантується: технічний доступ до сервера, резервних копій і логів обмежує можливості адміністратора, але владелец сервера може отримувати метадані.
- Telegram може тимчасово повернути RetryAfter або заблокувати доставку; помилки обробляються і повторюються через планувальник.
- Кнопка передачі username у зверненні є явною згоду студента показати його контакт адміну; при вимкненій галочці відсутній user ID і username.
- `ADMIN_USERNAMES` містить лише публічні username для розділу «Контакти»; ці дані адміністратор задає сам і може залишити змінну порожньою.
- Інтеграція зовнішньої пошти/хмарного сховища не передбачена.

## Чек-лист ручного тестування

- Додайте мінімум двох адміністраторів; кожен натиснув `/start`.
- Студент створює звернення з вкладенням; у обох адміністраторів не міститься `user_id`, `username` або ім’я студента.
- Адмін відповідає Reply і через «💬 Відповісти»; студент отримує копію.
- Адмін змінює статус; обидві карточки оновлюються, студент отримує тепле повідомлення.
- Заблокований студентовський чат показує адміну помилку Forbidden.
- Заблокований адміністратор пропускається без падіння розсилки; недоставка відмічається в SQLite.
- Анкета проходить усі 10 кроків, редагування і перегляд підтвердження.
- Перевірте ліміти звернень, `/note #0427`, `/note A12`, автоочистку, перезапуск бота та повторну доставку.
